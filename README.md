# Slack AI Demo

This repository is used to demonstrate AI-agent workflows through Slack.

The project uses fictional data only and may include:

- Interactive calendar dashboards
- Sample meetings and deadlines
- Company holidays
- Focus-time blocks
- Workflow automation examples

## Interactive calendar dashboard

Open `index.html` in a browser to view the sample scheduling dashboard.

The dashboard includes:

- A monthly calendar populated with fictional upcoming events
- Filters for meetings, deadlines, and focus-time blocks
- Search across event titles, owners, notes, and types
- Conflict highlighting for overlapping events on the same day
- Summary metrics and a selected-day detail panel
